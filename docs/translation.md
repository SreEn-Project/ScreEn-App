# 번역 기능

번역 파이프라인의 현재 구현, 캐시 방침, 속도 · 정확도 개선 계획. 결정의 이유는 [decisions.md](decisions.md) (D-030 · D-031 · D-036).
코드: `android/.../translate/`, `ocr/`.

## 현재 구현 (한 번 번역할 때)
1. **캡처**: 한 프레임. 영역이면 잘라낸다.
2. **문자 인식** (`ScreenTextRecognizer`): 긴 변 1600px로 줄여 ML Kit로 읽는다.
   - 자동 모드는 직전에 이긴 문자(처음 한국어) 하나로 먼저 읽고, 12자 미만이거나 신뢰도 0.8 미만이면 한 · 일 · 중 · 라틴 후보를 병렬로 돌려 가장 잘 읽은 것을 쓴다.
   - 글자가 12자 미만이면 색을 뒤집어 한 번 더 읽는다.
   - 입력 이미지 해시가 직전과 같으면 인식을 건너뛴다.
   - 자동 번역은 직전 화면과 격자를 견줘 바뀐 영역만 다시 읽는다 (`ChangedRegions`, #43). 바뀐 칸이 없으면 이전 결과를 쓰고, 40% 넘게 바뀌었거나 영역이 많으면 통째로 읽는다.
3. **정리**: `OcrCleaner`(잡음 줄 제거) → `OcrPostProcessor`(오인식 보정, #45) → `OcrBlockMerger`(이어지는 블록을 문단으로). 줄바꿈 · 줄 끝 하이픈은 이어 붙인다.
4. **언어 판별**: 한글 30% 이상이면 ko, 가나면 ja, 아니면 Language ID. 원문 = 대상이면 건너뛴다.
5. **번역**: 블록마다 ML Kit 온디바이스 번역을 동시에 돌린다 (`TranslationEngine` 인터페이스).
6. **표시**: 모든 블록이 끝난 뒤 한 번에 목록 · 문단 · 원문 위 덮기로 보여 준다.

## 캐시
- 파이프라인(`BlockCache`)에 블록(원문 글자) 단위 LRU 512개 둘: 언어 감지 결정, 번역 결과. 번역 키는 (엔진, 원문, 원문 언어, 대상 언어). 성공한 번역만 넣는다. 메모리에만 있어 서비스가 끝나면 사라진다.
- ML Kit 엔진 안에도 128개짜리 캐시가 있어 중복이다 → AI 엔진 전에 정리한다.
- AI 엔진이 붙으면 키에 모델 · 프롬프트 버전을 넣는다 (품질을 바꿔도 옛 번역이 나오지 않게).
- 디스크 영구 캐시는 하지 않는다 (효과 작음, 화면 글자를 저장하는 개인정보 부담). 하게 되면 Room + 보관 기간 제한.
- 캐시는 속도에만 도움이 된다. 잘못 번역된 결과가 고정될 수 있어, 사용자가 다시 번역하면 그 항목은 캐시를 무시하는 방안을 검토한다.
